# 🍲 Surplus-to-Shelter

![Live Demo](https://img.shields.io/badge/Demo-Live-brightgreen) ![Tech Stack](https://img.shields.io/badge/Stack-Node.js_|_Express-blue) ![Map](https://img.shields.io/badge/Mapping-Leaflet.js-orange)

> **Bridging the gap between food surplus and community shelters in real-time.** 

**Surplus-to-Shelter** is a full-stack, location-based platform built for the AMI Hacks hackathon. It empowers restaurants and event organizers to instantly broadcast excess food to nearby shelters through a live, interactive map interface.

## ✨ Key Features
* **Real-Time Logistics Map:** Interactive Leaflet map centered on Jaipur, Rajasthan, pinpointing exact pickup locations and calculating CO2 emissions saved.
* **Instant Broadcast System:** Organizers can submit surplus details directly on the map, syncing to the backend instantly.
* **Shelter Dashboard:** A clean, organized UI for shelter volunteers to claim deliveries and track incoming food streams.
* **Cross-Client Syncing:** True full-stack architecture running a custom Node.js/Express backend, tunneled publicly for seamless mobile and desktop access.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript, Leaflet.js mapping, Nominatim Geocoding.
* **Backend:** Node.js, Express, RESTful API architecture.
* **Hosting:** GitHub Pages (Frontend) paired with GitHub environments (Backend) for stable, cloud-native deployment.
